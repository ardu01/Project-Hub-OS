# Project Hub OS

Escritorio web futurista para acceder a los proyectos personales.

## Publicación

En GitHub: Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

## Añadir proyectos

Editar `projects.js`, incorporando un objeto a `PROJECTS` con `name`, `icon`, `category`, `description` y `url`.

La web funciona sin dependencias ni proceso de compilación.
